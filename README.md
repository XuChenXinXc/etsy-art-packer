## 一、 项目定位与核心作用

### 1. 解决什么核心痛点？
在欧美电商平台（如 **Etsy**、**Shopify**、**Printify**、**Redbubble**）上，有数以百万计的个人卖家在售卖**“数码壁画/装饰画（Digital Wall Art Downloads）”**。

买家购买后，需要把画打印出来装进自己的画框里。然而，欧美买家家里的画框���格千差万别：
- 有的买家相框是 **2:3 比例**（大画廊海报，如 24x36 英寸）；
- 有的是 **3:4 比例**（经典标准框，如 18x24 英寸）；
- 有的是 **4:5 比例**（宜家 IKEA 常见相框，如 16x20 英寸、8x10 英寸）；
- 有的是 **11x14 比例**（美国家庭常用肖像框）；
- 欧洲与澳洲买家则必须使用 **ISO 国际标准纸张比例**（A1、A2、A3、A4、A5）。

因此，**Etsy 平台官方与印刷服务商强制要求：卖家上传一个数码商品时，必须同时打包提供这 5 大主流比例的高清文件，且分辨率必须严格达到 300 DPI（印刷级标准）！**

### 2. 传统卖家的痛苦（人工苦力）
普通卖家（全职宝妈、插画师、AI 制图卖家）通常不懂复杂代码，他们每做完一张画，必须在 Photoshop 或 Canva 里手动重复 5 次操作：
1. 算像素与比例 $\to$ 裁切成 2:3 $\to$ 改 300 DPI $\to$ 导出 JPG；
2. 裁切成 3:4 $\to$ 改 300 DPI $\to$ 导出 JPG；
3. 重复完成 4:5、11:14 和 ISO 比例导出；
4. 手动新建文件夹，把 5 张图和一个买家打印说明文档压缩成 `.zip` 包。

**制作 1 个商品就要重复折腾 10~15 分钟；上架 20 款新品，整整一个下午都在做毫无意义的机械苦力！**

## 二、 本工具的应用场景与产品���值

### 应用场景
1. **Etsy 虚拟数码商品上架**：
   卖家只需把一张 Midjourney、Stable Diffusion 绘制的高清原图（或自己画的插画）直接拖进本工具，**只需 1 秒钟**，自动按照国际 5 大标准比例智能居中切片，并在图片二进制 Header 中注入真实的 300 DPI 元数据，一键打包成买家可以直接下载的交付 Zip 包。
2. **POD 衣服/海报印花校验**：
   Printify、Gelato 等代发货印刷平台如果检测到上传图片低于 300 DPI 会强制报错拦截。本工具直接输出合规文件，杜绝退单。
3. **附带买家尺寸指南（Customer Print Size Guide）**：
   Zip 包内自动内置专业英文版相框对照说明文本，极大减少买家因买错相框导致的售后差评与退款纠纷。
